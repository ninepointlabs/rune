Commands and shortcuts

Rune is built to be driven from the keyboard. One shortcut finds everything else.

The command palette

Press Ctrl+K, or File → Command palette…, and start typing. Every word you type has to match, so cite mla finds Citation style: MLA 9. Commands are listed with their shortcuts, so the palette is also a way to learn them.

Use ↑ ↓ to move, Return to run and Escape to close. Commands that don't apply right now, such as table commands outside a table, are dimmed.
